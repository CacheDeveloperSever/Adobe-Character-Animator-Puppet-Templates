## Usage

### For Puppet Import:
1. Launch Adobe Character Animator and create a new project.
2. Navigate to **File** → **Import** → **Puppet**.
3. Select the provided puppet file (`.puppet` or `.character`).
4. The puppet will appear in your project panel.
5. Drag the puppet to the timeline to begin animating.

### For Live Performance:
1. Connect your webcam and microphone.
2. Set up the camera using **Edit** → **Preferences** → **Camera**.
3. Select the puppet and click the **Start** button in the recording panel.
4. Control the puppet using your face, voice, and keyboard/mouse triggers.
5. Use the provided motion triggers for gestures and expressions.

### For Lip-Sync Setup:
1. Open the lip-sync template puppet.
2. Record or import an audio track into the scene.
3. Use the **Lip-Sync** panel to analyze the audio.
4. Apply the automatic mouth movements from the template.
5. Fine-tune the lip-sync by adjusting viseme assignments.

### For Streaming Integration:
1. Load the streaming avatar puppet from the repository.
2. Configure the **Stream** settings in Character Animator.
3. Select the puppet scene and start the session.
4. Use OBS or other streaming software to capture the Character Animator window.
5. Interact with your audience using the puppet's gestures and expressions.

### Customization Guide:
1. Open the puppet in **Rigging** mode.
2. Adjust the face mesh, eye tracking, and mouth positions.
3. Modify the behavior profiles to change personality traits.
4. Create custom triggers using **Scene** → **Triggers**.
5. Save your custom puppet for future use.
